# CNN学习笔记
## 定义概念
- 通过卷积核的窗口滑动提取局部图像的特征，不需要对于每个像素单独的处理而是一块一块的提取特征，容易学习到图像的不同小特征，适合识别图像问题
## CNN组成
### 1.卷积层
- 主要作用就是提取图像的局部特征，含有多个卷积核，每个卷积核都可以提取一种图像特征，输出通道数就是卷积核数量
- 卷积核就是一个小矩阵，通过在输入图像的滑动，每次矩阵乘法得出数值就是这一块的特征值，就是做点积
- 权值共享就是同一个卷积核在滑动时，内部矩阵数值是相同的，一整个图像的参数是共享的，这样可以大幅减少参数量 
### 2.池化层
- 主要作用就是减少参数量 计算量 提纯特征，把大图像压缩成小一点的 并且放大某些主要特征
### 3.全连接层
- 先展平将多维特征转化为一维向量，汇总所有特征内容，通过全局信息对图像做出判断
## 整体流程
- 输入图像->卷积层->池化层->全连接层
- 流程中可能有多次的卷积+池化
## 遇到问题
- 如何选择卷积核的大小？
- 卷积核滑动窗口的计算是怎么算的？
# 问答题
1. 卷积层由多个卷积核组成，帮助CNN提取图像的局部特征
2. 相较于全连接层，卷积层可以权值共享，参数量大幅减小，不需要每个值都配有一个权重，还能够保留空间信息
3. 不一定，小的卷积核堆叠相对于相同感受野卷积核使用的参数量较少，且可以用更多非线性激活函数，训练效果更好
4. 池化层就是减少尺寸，减少计算量，只保留显著特征。 Max Pooling-取最大值，能够保留最显著特征。Average Pooling-取平均值，保留图像整体信息
5. 就是输出图像上一个像素对应输入图像上的区域大小

# 思考
## 图像变化
| 测试条件 | 准确率 | 相比原始下降 |
| :--- | :--- | :--- |
| 原始 | 92.74% | - |
| 变亮 | 91.91% | -0.83% |
| 模糊 | 89.01% | -3.73% |
| 旋转 | 88.70% | -4.04% |
| **遮挡** | **73.90%** | **-18.84%** |
- 遮挡对于模型影响是最大的，下降了约百分之十九
- 目前选择在训练时加入随机遮挡样本，增强数据
## 模型优化
- 加入数据增强（随机遮挡）后，模型在遮挡测试集上的准确率从 73.90% 提升到 87.09%，但原始测试集准确率从 92.74% 降至 88.38%，加入遮挡的训练数据让训练难度增加，使得原始测试的准确率下降，但是应对遮挡数据的准确率提升更多。
