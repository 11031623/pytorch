# 问题二的分析与思考
## 2.1实验结果分析
- 在训练过程中，虽然loss值持续下降，但也只是从180到90多最终的loss依然很高，说明训练表现很差，线性模型对于非线性数据的拟合程度很低
- 最终评价指标中的MSE大小为99说明预测值和真实值之间的误差很大， R²为负值也说明了预测能力非常差
- 综上结论为线性模型在非线性数据的任务表现很差
## 2.2实验结果对比分析
### 对比表格
| 对比维度 | 线性模型 | MLP（全连接神经网络） |
| :--- | :--- | :--- |
| **模型结构** | 1 层 Linear(10, 1) | 3 层 Linear + ReLU |
| **参数量** | 11 | 4929 |
| **训练最终 Loss（第 500 轮）** | 96.25 | 1.09 |
| **测试 MSE** | 98.47 | 1.64 |
| **测试 R²** | -3.32 | 0.9281 |
| **训练收敛情况** | 500 轮仍在缓慢下降 | 500 轮内快速下降并趋于平稳 |
### 分析
- 通过训练过程和最终评价可以看出 mlp最终loss和mse都达到1左右 相较于线性模型性能的提升非常大，
- 结论 mlp可通过非线性函数和隐藏层去拟合出近似的非线性函数，而线性模型始终无法去拟合非线性规律
## 思考题
1. 模型能力从哪里来？——为什么改变网络结构可能会影响模型学习复杂数据规律的能力？
   -  网络结构决定了上限，线性结构无论参数和模型复杂程度多好也无法去拟合非线性函数 其他条件相同只是改变网络结构得到的结果差异非常大
2.  “更深”一定意味着“更强”吗？
   - 不一定 该问题的多层线性网络并没有让模型的表达能力发生本质变化，没有激活函数，只是多次的线性复合最后还是线性模型，本质是不变的
3. 模型越复杂越好吗？
   - 当隐藏层和神经元变多后，神经网络确实变复杂了，训练集的表现会明显变好，但是当样本数少时，模型会过拟合，导致在测试集上表现变差。并不是越复杂越好
